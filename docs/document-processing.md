# 图表处理与表格理解

打开资料详情，点击 **查看 / 处理图表**。处理后可查看格式化表格，点击单元格追溯来源，导出JSON或Markdown，并选择明确的数据行求和、平均、最小值或最大值。结果进入原资料的本地检索索引；原件、原索引和历史保留，不新增已核实事实或批准核验。

## 支持范围

| 输入 | 本机处理 | 保留内容 |
| --- | --- | --- |
| DOCX | OOXML原生解析 | 多级表头、横纵合并、原文段落/单元格位置、表名和邻近注释 |
| XLSX | openpyxl | 工作表、坐标、合并关系、原值、已有公式缓存；不运行公式、宏或外部链接 |
| CSV、HTML | csv、BeautifulSoup | 表头、单位、空白；HTML保留声明的合并关系 |
| PDF原生表 | pdfplumber | 页码、表格/单元格边界和原生文字 |
| 图片、扫描PDF、DOCX嵌入图 | RapidOCR + 本机视觉模型 | OCR框、置信度、原图、行列重建、图表轴/图例/标签说明 |

当前真实验收覆盖清晰中文有线表、带数值标签的柱状图、扫描表格PDF及原生文档表格。复杂跨页表、多栏、低清晰度和图片合并关系不保证自动复原。精确数值只读可见标注，不按柱高估算。所有OCR和视觉结果均为机器识别草稿，需核对原件。

## 理解与计算

检索行表示同时携带行标签、多级列名、期间、单位和表注，标明是结构化表示而非原文连续段落；图片行另标机器识别重建。支持片段保留整行上下文，可回溯工作表坐标、DOCX位置或图片/页码。

空白不等于零；未缓存公式显示“公式结果未缓存”，不冒充空白或计算结果。计算只接受明确选择的纯数值数据行，拒绝重复行、表头、表注、重复合并格、空白、未缓存公式及百分比。独立“单位”列必须一致，不自动换算；用户仍需确认指标、期间和统计口径适合该运算。输出附输入单元格与表头来源。

## 运行与权限

问答继续使用当前 `config/agent.json` 的Bonsai。图形理解独立使用 `config/document-processing.json` 中的CPU Qwen3-VL-2B，不替换问答接口或回退付费模型。OCR也在CPU运行。视觉权重及投影约1.55GB，位于 `work/document-models`，manifest保存下载版本、大小和完整SHA-256。视觉服务仅绑定127.0.0.1，页面关闭时清理其自有进程。

依赖在 `web/requirements.txt`；官方模型下载脚本为 `scripts/setup_document_models.py`。维护环境已完成安装与有限样例验收。移植时需提供兼容llama-server并调整上述非敏感路径配置。模型不随公开源码或现有安装包分发，本轮未重建安装器。

每轮默认最多12个PDF页、4幅图像，页面可调整起始页和本轮上限。报告列出累计覆盖、剩余项与下一批起始页。任务逐步骤保存，可暂停、继续、重试；重启后标为中断，等待继续。原生表格无需模型或密钥。视觉分析要求资料允许模型读取且非受限，调用前后和提交前复查授权与版本。移出检索后保留解析，但搜索和Agent不再引用。

## 本轮问答修复与边界

模型只选择来源片段标识，后端生成连续原始引文与真实定位。格式映射允许HTML、空白和标点差异，拒绝跳字拼接和修改数字；相关对象上下界冲突时按原文保留常规范围与例外，不合成一个统一最大值。Bonsai SDK消息合并为单个前置system，保留medium思考，问答思考预算有界。失败诊断只保存安全元数据，不保存思考正文或凭据。

可追溯校验不能证明所有生成结论都被原文充分支持；复杂语义、统计口径与识别质量仍需人工复核。
