# 研究可视化报告

把资料组织成读者可以理解、比较和追溯的视觉报告。表达形式由内容关系与数据决定；同一报告可以组合图表、表格和原理示意，不固定套用若干文字卡片。页面主视觉应回答读者最关心的问题。

## 工作方式

1. 明确读者、展示目的和核心问题；未指定时采用适合一般读者的简洁讲解，不增加必填步骤。用户明确要求生成或修改报告时执行；普通问答保持原有行为。
2. 从获准使用的原文、附件或检索命中片段中整理数据。先形成数据契约：指标、单位、时间或实验条件、对象/总体、比较口径、来源位置、事实性质与缺失值。一个数值不能脱离它的行列标题和实验设置。
3. 选择表达方式：有序时间/数值变化用折线图，类别差异用柱状图，同一整体的互斥组成用饼图；指标口径不同、样本少或需要精确读数时用表格。方法、机制和系统用流程/结构图。详细取舍与检查见[图表选择与数据契约](references/chart-design.md)，制作定量内容前读取。
4. 形成视觉叙事：突出主要结果，按需要展开研究路线、关键技术、结果比较与适用边界。图表配一句有依据的结论，详细引文按需展开。让图形解释内容，而不是让装饰图标占位。
5. 按当前环境的工具与输出要求执行。在研知知识库中，读取[内置Agent执行约定](references/knowledge-base.md)，用声明式场景和受控工具，不输出任意网页脚本。若用户只要一个图或表，完成该图表即可。
6. 验收数据与显示：检查数值、单位、排序、缺失、比例分母、轴标签、图例、截断和窄屏；实际操作节点、系列选择及引用入口。只有完整结果通过校验后才保存正式版本。出错时修复对应场景，保留已通过部分，有限重试后保留草稿。

## 关键约束

- 折线的横轴必须是有序时间或连续数值，不能为算法名称编造日期或连成趋势。方法A/B的误差比较通常用柱状图或表格。
- 饼图必须说明整体与分母，组成互斥且覆盖这个整体；负值、缺失、不同任务误差或MAE/RMSE/R²的混合不构成组成比例。没有可靠分母时改用柱状图或表格。
- 保留原始精度与单位。未知不等于0；不跨缺失连线。原文只有平均值时不能创造波动曲线、误差条、显著性或样本分布。
- 计算占比、差值或变化率必须说明公式、分母和使用的原值，区分原文报告与派生计算。不把来源报告值写成独立实测或外部已核实事实。
- 一个表格可以并列不同指标，但列标题须分别标单位；图表直接比较则必须共享口径。标准化和单位换算需有明确依据，不能为了画图临时混合统计范围。
- 图形与表格保留来源定位和资料版本；用户授权、地域与原文变化的校验继续生效。Skill本身不扩大外部调用、发布或上传资料的权限。
- 图表中的结论范围不能超过数据。视觉整理、全文索引完成和资料确认，都不等于独立验证了论文实验或全部外部事实。

## 完成标准

读者能看出“比较什么、单位是什么、适用什么条件、结论从哪里来”；主要交互有效，数据可追溯，报告已按用户要求保存或交付。说明本次实际验证的范围；草稿和未完成图表不作为成品交付。
