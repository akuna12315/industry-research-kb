# 图表选择与数据契约

| 问题 | 首选表达 | 数据要求 |
| --- | --- | --- |
| 随时间如何变化 | 折线图，axis=time | 日期真实、粒度一致、同一指标与统计口径 |
| 随循环次数/训练轮次如何变化 | 折线图，axis=number | 真实x坐标、x指标和单位；只有终值时不用曲线 |
| 不同算法/地区/样本谁高谁低 | 柱状图，axis=category | 类别明确、同一指标单位、同一实验/统计条件 |
| 一个整体由什么构成 | 饼图，axis=category | 同一总体，互斥穷尽组成，非负且无缺失；2至8项 |
| 需要同时看MAE、RMSE、R² | 表格，kind=table | 每列独立说明指标和单位，不把三种指标画成一个饼 |
| 数据口径不同或数值不完整 | 表格，保留未知与备注 | 标明条件差异，不做直接排名 |
| 一个方法或系统怎样工作 | flow/architecture/concept | 对象、关系和说明的原文依据；没有依据的组织关系标为分析归纳 |

## 定量准备

给每组数据记录：指标、单位、对象/总体、地区或非地域性实验范围、期间/工况、比较口径、实际/计划/来源报告、精度、缺失情况、引用定位。实验中没有地理含义时如实写实验对象范围，不强行套入知识库默认地区。

同一图内的每个类别都要核对指标和条件；相同名称不代表相同口径。保留表头、表注和单位，必要时补检索相邻片段。没有这些上下文时，表格中显式保留未知，不猜测。

折线图至少两个有依据的点；横坐标排序，重复位置或冲突值分别处理，不把空值改为0，也不跨空值连线。类别柱状图可以共享同一统计期间，不需要为每个算法设置不同日期。

饼图不是通用的“百分数图”。误差率、准确率以及两种算法各自的得分不表示同一整体的组成。百分比组成须合计约100%（只容忍声明精度下的微小舍入差）；原始数量的组成须有来源支持的整体总量，合计须与总量一致。份额由本机按value/total*100计算，不能让模型任意填扇区角度。未覆盖的部分不能悄悄删掉后重新归一化。

## 显示与解释

- 标柱状图零基线，直接标数值与单位；长类别名换行，避免裁切。
- 折线横轴按真实间距，不能把间隔1天与1年画成相同时间间隔。数值横轴标名称与单位。
- 饼图用平面扇区，类别与份额同时可读；保留精确值表格及来源。零值仍在数据表中显示，不画虚假的可见扇区。
- 多指标表格分别标单位、对齐数值，脚注说明统计范围。定性结论与数值分列，避免仅靠颜色表示优劣。
- 标注原文报告、计划目标或派生计算。只有数据支持时才讨论改善幅度、趋势或领先；不能从可视化推导未检验的因果或显著性。
- 交互图保持原值表与引用入口。需要供论文/PPT使用的静态图片时，按用户要求导出可用格式，核对字号和尺寸；没有实际导出能力时不声称已交付图片文件。
