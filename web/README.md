# 页面使用指南

完整入门、功能和截图见[根README](../README.md)。首次运行执行 `python scripts/init_workspace.py`；使用 `start-web.ps1` 会自动完成这一步，已有配置不覆盖。

## 研究

在顶部选择行业或明确选择全部行业，配置自己的兼容模型后提问。研究工具可展开进行网页搜索和有界采集；收起工具或切换页面不会主动终止当前回答。来源与资料中的指令不构成执行授权。

默认允许按本轮问题有界调查和收录未核验资料，可直接说“仅回答”“不要归档”“不加入检索”或“不添加信源”。preferred来源允许发现公开原始入口，only严格限定已启用来源和允许路径。网页收录须本轮读过原文；摘要只作线索。定时采集不随页面自动开启。

## 知识库

导入时选择资料类型、来源、版本、范围和加入检索状态。可选核验记录不阻挡检索，也不把入库等同于事实核实。资料退出检索后保留原件、解析和历史，但不再参与全文搜索或Agent引用。受限资料不能授权给模型。

索引在本机以1200字符分块、相邻180字符重叠；可选择语义召回与专用重排。回答引文与位置由后端根据支持片段生成，并复查版本和读取授权。修改适用范围、来源或原件后，旧解析会失效，需要重新处理。

## 图表与表格

打开资料详情 → 查看 / 处理图表。表头可以自动识别或手动指定；PDF可以设置起始页、页数和图像预算。机器识别只代表处理范围内的草稿，不表示全文外部事实已核实。可暂停、继续、重试，重启后不自动恢复模型调用。

表格可查看单元格来源、导出JSON/Markdown及选行计算。空白不等于0；Excel公式只读已有缓存，缺缓存不执行公式。计算需要明确数据行、相同单位和适当的统计口径。详细步骤见[图表说明](../docs/document-processing.md)。

## 页面库

明确要求生成可视化页面并选择资料后，助手设计场景、逐个校验并保存。支持流程、结构、概念、对比、表格和有数值依据的统计图。引用、数字支持和版本检查通过后才保存正式页面；失败场景隔离，已通过内容作为草稿保留。用户可继续处理、调整单图、改展示或更新研究。

已保存页面的查看、演示和引用展开不调用模型。当前轻量页面模式称为简约版；详细版属于后续规划，不作为已实现功能宣传。

## 运行配置

模型接口、协议与型号由用户配置，不自动切换付费厂商。密钥只存在服务内存或用户环境中，重启前保存非敏感配置，并注意页面输入的密钥会被清空。对话历史默认关闭；偏好记忆需用户保存和授权，不能作为事实依据。

问题排查先核对当前服务、资料授权、版本和任务覆盖范围；不要通过放宽引用校验让失败结果冒充成功。自动回归与真实模型验收的边界见[测试说明](../docs/testing.md)。
