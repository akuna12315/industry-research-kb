# 页面与 Agent

启动与配置见 [根 README](../README.md)。公开版初始无行业、实际资料、模型密钥或定时任务。

## 日常使用

1. 创建行业或使用林草工作台的“新增地区”；设置研究地区、分类和来源。采集开关默认关闭，切换默认行业不会开启调度。
2. 在证据库检索已核验记录，查看原文链接、日期、事实状态、时效和历史。`review_due` 表示待复核，不能据此判断事实错误。
3. 进入专业资料管理，上传原附件并补充适用地区、版本、项目阶段和获取权限。目录资料与事实证据分别管理，上传不表示已核验。
4. 在“Agent 设置”配置支持工具调用的模型 API，填写接口、协议、模型和密钥。默认问答只读，单行业“研究并归档”才开放网络调查和事实写入。
5. 用网页搜索发现线索，再选择“批量采集”。采集完成可让 Agent 读取原文、检查已有事实并分类归档。

## 对话示例

- 只读：“检索当前地区的国土绿化设计依据，区分全国与地方适用范围，列出版本、来源和缺口。”
- 单行业研究：“搜索最近一周的官方政策，打开原文，将有价值的变化归档，说明未核验问题。”
- 批量采集：“从当前启用信源读取最多10页、深度1，说明失败来源并整理证据。”
- 添加信源：“将这个公开官网加入本行业来源。”需另勾选“允许按我的要求添加信源”；only 模式由用户在来源页面调整。

搜索摘要和采集候选不是事实。每轮新增证据受行业上限约束；已有事实修订保留历史。采集不推进连续调查覆盖日期，真实调查结果另用 `finish-run` 记录。

## 专业资料与跨地区使用

支持 PDF（最多300页）、DOCX、TXT/MD/CSV 文本提取，普通上传每份10MB、正文最多20万字符。图片、TIF、GeoJSON、ZIP 只管理附件，不进行 OCR、解压或空间分析。

大型 DOCX 使用 `scripts/import_material.py` 本地导入，最高100MB、正文 XML 64MB、解压总量500MB、文字200万字符。不开放任意路径 HTTP 接口，不执行 Office 或访问外链。索引保留段落、表格行、单元格位置；详情支持全文分段检索、分页和原件下载。缓存页数不作为渲染核对后的正式页码，图片与公式版式需核对原件。

资料默认 `internal`、`unknown` 和 `model_allowed=false`。模型只读取明确授权且非 restricted 的相关片段。资料级别是本地标记，不是多人访问权限系统。标准未取得完整正文时不能编造条款；项目终稿不代表已批复或验收。

地区可设置 `research_regions`、`primary_region`、`comparison_regions`。范围变化同步未修改的模板查询，保留自定义查询及已有资料适用地区。新增地区不猜测地方来源，不复制旧省份事实。全国基础档案以 `specialty=forestry`、`library_role=national-foundation` 标识；共享检索标明所属档案，地区模型只引用其中公开且明确授权的资料片段。公开版不附带真实基础库内容。

偏好记忆需手动保存并授权模型读取，不作为事实或执行指令。`config/knowledge.json` 默认关闭对话历史；开启仅保存未来完成的提问及回答，按行业分开，最多每组50轮，不自动将历史全文发送模型。Agent 运行记录保存工具步骤和状态，不保存最终回答正文；工具参数可能包含查询词，运行记录应留在本地。

## 模型、搜索和采集配置

`scripts/init_workspace.py` 从 `config/*.example.json` 生成本地配置，已有文件不覆盖。模型支持 OpenAI Chat Completions / Responses，协议须与后端匹配并支持工具调用。模板地址及模型名需替换为实际配置。密钥仅服务内存或自己的 `KB_MODEL_API_KEY` 环境变量，重启需重填；切换接口来源不沿用旧密钥。

搜索默认免密钥 DDGS/Bing，可切换引擎或接入启用 JSON 的自有 SearXNG。采集支持公开 HTML、文本、RSS，每批最多50页、深度0至3，同站跟踪、停止和指纹去重。遵守 robots.txt 与跨任务同站限速。失败保留原因，不能据此说资料不存在。

来源原文最多2MB，模型读取片段最多18000字符并标注截断。网页正文临时存在内存，磁盘仅保存短摘录、链接、指纹和状态；重启后需重新读取。此限制不影响用户主动导入的本地专业资料原件和索引持久保存。

## 服务边界

仅监听127.0.0.1；写接口要求本地请求标识并拒绝跨站 Origin。Agent 无任意文件、Shell、外部消息或购买工具。网页及附件指令仅视为资料。来源拒绝内网地址并校验重定向，only 模式在缓存读取和归档时也重新检查最新目录限制。

真实公网 DNS 校验后固定连接 IP，并保留域名 TLS 校验；本机198.18/15代理映射会通过 Cloudflare HTTPS DNS 确认公网地址。公开采集不绕过登录、付费墙或访问控制。

厂商模型会收到本次研究所需的授权片段，搜索服务会收到查询词，目标站点会收到采集请求。不要把密钥输入问答、资料或记忆。常见凭据格式会拒绝或隐去，但不保证识别任意字符串。

本地配置、行业资料、附件、索引、记忆、运行记录、报告、截图和密钥均不得提交公开仓库。请勿使用强制添加绕过 `.gitignore`。
