# 页面与 Agent

安装与测试见 [根 README](../README.md)。公开版初始为空白配置，不含实际行业、资料、密钥或定时任务。

## 日常流程

顶部选择当前行业即保存；“管理”集中创建、搜索、重命名、删除和恢复。删除仅隐藏档案并放入回收站，保留原件、事实和历史；恢复不切换当前选择或开启采集。全部行业用于显式跨行业检索，单行业不自动附加其他档案。

在知识库添加 PDF、DOCX、TXT、MD、CSV 等资料，导入窗口与列表直接显示“加入检索”。新资料默认开启，既有关闭状态保留；restricted 资料不能开启。退出检索保留原件与历史，并排除全文召回和 Agent 引用。核验是可选的独立质量记录，加入检索不表示已核验。

加入后在本机按1200字符固定切分、相邻重叠180字符建立索引，不依赖模型或密钥。普通问答先本地召回、模型重排，再根据命中原文作答；重排失败明确说明本地排序回退。索引和引用保留定位与版本指纹，更换附件、撤销授权或切换范围后不可继续使用旧缓存。

附件上传上限100MB。PDF 最多解析300页，普通正文提取有长度限制；大型 DOCX 的本地导入支持正文 XML 64MB、解压总量500MB、文字200万字符。图片、扫描件、公式和复杂版式不做 OCR 或渲染校验，需核对原件。系统不执行 Office、解压任意附件、访问文档外链或进行空间计算。

## 助手调查与来源

模型设置支持 Chat Completions / Responses，须匹配实际服务并支持工具调用。首次接口与型号为空，用户保存后使用当前配置；不自动切换厂商。密钥仅内存或自己的环境变量，切换接口来源不沿用旧密钥，重启后页面填写的密钥需重填。

助手默认按当前问题有界调查、收录资料、添加 preferred 信源。用户明确说“仅回答”“不保存”“不入库”“不加入检索”时，本轮不收录或扩展信源；“不添加信源”仅关闭来源扩展。only 模式始终严守已有启用入口和允许路径。跨行业可检索，写入仍需用户选定单个行业。

网页搜索摘要只作线索，原文读取后才可收录。自动收录通过字段、日期及逐字引用校验后保存有界摘录为未核验资料，不自行批准核验或生成 confirmed 事实；重复收录尊重用户原先退出检索的选择。公开正文只在内存暂存，磁盘保留短摘录、链接、状态与指纹，重启后需重读。

搜索默认 DDGS/Bing，可切换引擎或自配 SearXNG。公开采集遵守 robots.txt 与同站限速，限制页数、深度和单页大小，拒绝内网地址并检查重定向。不绕过登录或付费墙。失败保留原因，不据此推断资料不存在；候选和普通收录不推进行业连续覆盖截止。

## 生成可视化研究页面

明确要求“把这份资料整理成网页”，选择目标资料后才执行页面生成。技能位于 [research-visual-report](skills/research-visual-report/SKILL.md)，按内容选择流程、结构、概念、比较、表格、折线图、柱状图、饼图或时间轴。查看和演示已有页面不再次调用模型。

图表须有逐字原文支持，包含指标、单位、对象、期间与比较口径；饼图还需明确整体和分母。缺测留空，不编造日期、数量、类别或引用。只使用所选资料，不能用其他项目代替目标文档。

后端提供原文摘录编号，绑定文字和来源；结构、引用、数据支持与版本均通过后才正式保存。单个场景失败独立隔离，按字段提示有限重试，不重复保存坏页面；保留已通过场景及草稿供恢复。无法满足图表口径时可受控改为表格，仍须逐字核对数据。

浏览器只渲染受校验的结构化数据与本地 SVG，不执行模型生成的 HTML/JavaScript，不加载外部绘图库。助手单图可直接调用 draw_research_chart；独立页面使用页面场景工具，两者用途分开。

## 本地数据与边界

偏好记忆需手动保存并授权，对话历史默认关闭，开启仅保存新完成的问答及图表短摘录；不自动发送历史全文。用户配置的外部模型只收到本轮研究必要片段，搜索服务收到关键词，原网站收到采集请求。

服务仅监听127.0.0.1，写请求校验来源。Agent 无任意文件、Shell、购买或外部消息工具。资料级别是本地标记，不构成多人权限系统。网页及附件中的指令仅视为资料。

本地配置、行业资料、原件、索引、记忆、对话、运行记录、报告、截图及密钥不得提交公开仓库，请勿强制添加绕过 .gitignore。
