# 页面与Agent

启动与配置见 [根README](../README.md)。公开版初始无模型密钥、行业或定时任务。

## 对话示例

- 只读：“查询合同证据，说明来源、核验日期和限制。”
- 单行业研究并归档：“搜索最近一周的官方政策，打开原文，将有价值的变化分类归档，列出未核验问题。”
- 单行业批量采集：“从当前启用信源读取最多10页、深度1，说明失败来源并整理有价值的证据。”
- 添加信源：“将这个公开官网加入本行业来源。”需另勾选“允许按我的要求添加信源”；only模式由用户在来源页面调整，Agent不扩大边界。

采集结果属于候选，搜索摘要不是事实。入口导航、重复内容和无依据数字不能直接入库。原文最多2MB，模型读取正文最多18000字符，截短时会标注；不能据此声称完整行业覆盖。

## 配置

`scripts/init_workspace.py` 从 `config/*.example.json` 创建本地配置，已存在文件不覆盖。

模型连接支持 OpenAI Chat Completions / Responses，协议须与后端匹配并支持工具调用。模板地址和模型名必须替换为自己的实际配置。密钥仅内存/env，重启需重新填写；厂商或地址变更不沿用旧密钥。

网页搜索配置独立于模型，默认无需密钥。在“Agent设置”中切换引擎或填写启用JSON接口的自有SearXNG实例。受限、超时和robots禁止会记录实际失败，不能绕过。

记录位于本地 `reports/agent-runs/`、`reports/crawls/`，各行业 `data/crawl-index.json` 保存URL/内容指纹。正文不整篇写盘。下载的本地简报包含证据原始链接、事实状态、日期与统计口径。

## 安全边界

仅监听127.0.0.1；写接口要求本地请求标识且拒绝跨站Origin。Agent无任意文件读取、Shell、外部消息或购买工具。网页指令只是资料。拒绝内网来源，校验重定向；only模式逐次限定目录。批量抓取遵守robots.txt，跨任务同站限速；最多两批采集及两个Agent任务。

不要把本地配置、运行记录、截图、密钥或行业资料提交到公开仓库。 `.gitignore` 默认排除这些文件；运行例子产生的事实必须真实核验，模板不得当成已执行调查。
