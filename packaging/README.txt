研知 · 行业知识库 0.1.5（Windows x64）

安装与首次使用
1. 运行 YanZhi-Setup-0.1.5-x64.exe，在 Windows 管理员授权窗口选择“是”，然后按提示安装。无需另装 Python。
2. 安装完成后从桌面或开始菜单启动应用。启动器打开本机浏览器工作台，日常启动无需管理员授权。
3. 新知识库的行业档案、默认行业、模型提供方、接口地址和型号均为空。不预置真实来源、资料、证据、密钥、偏好或对话。
4. 在“设置 → 档案与范围”创建行业，在“设置 → 模型与助手”填写自选的模型接口与型号。配置前显示“未配置模型”。
5. 单个附件上传支持最高100MB（100,000,000字节）。
6. 知识库统一为资料检索：上传或网页资料开启“加入检索”后建立索引，核验为可选质量记录，不再要求生成独立知识证据。搜索结果显示原文片段，可点击“定位原文”。本机查阅不要求模型授权；助手只引用已加入检索且非受限的相关片段。已有证据与历史保留。
7. 资料导入、手动核验和本机全文索引无需模型；模型问答和自动核验需要可用接口。安装包不包含模型或模型权重。

已有安装升级
升级保留原知识库中的行业、模型配置和导入资料，不会替用户删除或重置。
之前版本已生成的默认档案和模型配置属于旧库，升级后仍会保留。
如需完全空白的库：在启动器中点击“停止服务 → 新建空白库”，选择或新建空目录，再点击“打开工作台”。
原库保留，可通过“选择知识库目录”切回。不要为了清理默认信息直接删除含导入资料的旧行业目录。

本地资料与服务
默认知识库目录：%LOCALAPPDATA%\YanZhi\KnowledgeBase
该目录不可写时：安装目录\UserData\KnowledgeBase。卸载保留 UserData，迁移时请备份该目录。
已有库根目录应含 config\industries.json、agent.json 和 automation.json。
关闭浏览器标签页不会停止服务；关闭启动器或点击“停止服务”才会停止。
请勿同时使用源码服务和桌面应用打开同一份库；已有网页服务请先在其原启动窗口停止。
选择已有库会按现有应用流程恢复全文索引；请先保留自己的备份。
本机仅监听 127.0.0.1；默认端口 8766 被占用时自动使用空闲端口。
新库自动采集和对话保存默认关闭。本安装包不会自动创建定时采集任务。
升级和卸载保留资料目录、模型设置及授权记录。卸载前先关闭启动器。

运行要求与限制
支持目标为 Windows 10 1809及以上 / Windows 11，64位 x64 处理器。
这是本机 Web 工作台的桌面启动与安装版本，界面通过默认浏览器使用。
本版本未做代码签名，Windows 可能显示发布者未知提示。
